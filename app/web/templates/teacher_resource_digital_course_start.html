{% if current_lang == 'va' %} Un curs nou sol començar amb informació repartida entre correus, plataformes, reunions i documents. La meta no és crear un sistema complex, sinó decidir des del principi on guardar cada cosa i com localitzar-la després. {% else %} Un curso nuevo suele empezar con información repartida entre correos, plataformas, reuniones y documentos. La meta no es crear un sistema complejo, sino decidir desde el principio dónde guardar cada cosa y cómo localizarla después. {% endif %}

{% if current_lang == 'va' %}Separa identitat personal i treball del centre{% else %}Separa identidad personal y trabajo del centro{% endif %}

{% if current_lang == 'va' %}

Usa el compte corporatiu quan el centre el proporcione i evita reenviar automàticament informació professional a comptes personals.

  • Compte institucional per a correu i plataformes.
  • Perfil de navegador independent per al centre.
  • Contrasenyes úniques guardades en un gestor fiable.
  • Doble factor d’autenticació quan estiga disponible.
  • Tancament de sessió en equips compartits.
  • Notificacions configurades per a evitar barrejar àmbits.
{% else %}

Usa la cuenta corporativa cuando el centro la proporcione y evita reenviar automáticamente información profesional a cuentas personales.

  • Cuenta institucional para correo y plataformas.
  • Perfil de navegador independiente para el centro.
  • Contraseñas únicas guardadas en un gestor fiable.
  • Doble factor de autenticación cuando esté disponible.
  • Cierre de sesión en equipos compartidos.
  • Notificaciones configuradas para evitar mezclar ámbitos.
{% endif %}

Una estructura curta funciona millor que desenes de carpetes buides. Comença amb categories estables i afig subdivisions només quan siguen necessàries.

No guardes dades personals de l’alumnat en ubicacions o servicis que no estiguen autoritzats.

{% if current_lang == 'va' %}Anomena els arxius per a entendre’ls dins de sis mesos{% else %}Nombra los archivos para entenderlos dentro de seis meses{% endif %}

{% if current_lang == 'va' %}

Usa noms breus, ordenables i coherents. Una fórmula senzilla evita arxius com definitiu_final_2.

  • Data en format AAAA-MM-DD quan importe l’ordre.
  • Grup o nivell.
  • Tipus de document.
  • Tema o activitat.
  • Versió només quan existisquen diverses revisions.

Exemple: 2026-09-08_2ESO_Activitat_inicial_v01.pdf

{% else %}

Usa nombres breves, ordenables y coherentes. Una fórmula sencilla evita archivos como definitivo_final_2.

  • Fecha en formato AAAA-MM-DD cuando importe el orden.
  • Grupo o nivel.
  • Tipo de documento.
  • Tema o actividad.
  • Versión solo cuando existan varias revisiones.

Ejemplo: 2026-09-08_2ESO_Actividad_inicial_v01.pdf

{% endif %}

{% if current_lang == 'va' %}Unifica calendari, tasques i terminis{% else %}Unifica calendario, tareas y plazos{% endif %}

{% if current_lang == 'va' %}

Les dates poden arribar per correu, reunions, plataforma i missatges. Porta-les a un únic calendari de referència.

  • Avaluacions, reunions i claustres.
  • Lliuraments de documentació.
  • Activitats complementàries.
  • Dates d’exàmens o projectes.
  • Recordatoris per a preparar materials.
  • Terminis administratius personals.

Distingix esdeveniments amb hora de tasques que requerixen treball previ. Una data límit sense recordatori sol arribar massa tard.

{% else %}

Las fechas pueden llegar por correo, reuniones, plataforma y mensajes. Llévalas a un único calendario de referencia.

  • Evaluaciones, reuniones y claustros.
  • Entregas de documentación.
  • Actividades complementarias.
  • Fechas de exámenes o proyectos.
  • Recordatorios para preparar materiales.
  • Plazos administrativos personales.

Distingue eventos con hora de tareas que requieren trabajo previo. Una fecha límite sin recordatorio suele llegar demasiado tarde.

{% endif %}

{% if current_lang == 'va' %}Prepara plantilles reutilitzables{% else %}Prepara plantillas reutilizables{% endif %}

{% if current_lang == 'va' %}

Les plantilles reduïxen decisions repetides i mantenen una presentació coherent. Crea primer les que utilitzaràs de veritat.

  • Fitxa o activitat amb capçalera comuna.
  • Rúbrica bàsica editable.
  • Registre de reunió.
  • Llista de comprovació per a publicar materials.
  • Presentació amb tipografies i grandàries llegibles.
  • Document de seguiment setmanal.
{% else %}

Las plantillas reducen decisiones repetidas y mantienen una presentación coherente. Crea primero las que vayas a utilizar de verdad.

  • Ficha o actividad con cabecera común.
  • Rúbrica básica editable.
  • Registro de reunión.
  • Lista de comprobación para publicar materiales.
  • Presentación con tipografías y tamaños legibles.
  • Documento de seguimiento semanal.
{% endif %}

  • Esborrany en la carpeta de treball.
  • Revisió de contingut i format.
  • Exportació a PDF quan es compartirà.
  • Publicació en la plataforma corresponent.
  • Còpia del material final.
  • Arxiu o eliminació d’esborranys innecessaris.
{% else %}

Define qué ocurre desde que empiezas un documento hasta que queda archivado.

  • Borrador en la carpeta de trabajo.
  • Revisión de contenido y formato.
  • Exportación a PDF cuando se vaya a compartir.
  • Publicación en la plataforma correspondiente.
  • Copia del material final.
  • Archivo o eliminación de borradores innecesarios.
{% endif %}

{% if current_lang == 'va' %}Prepara el treball sense connexió{% else %}Prepara el trabajo sin conexión{% endif %}

{% if current_lang == 'va' %}

La sincronització no substituïx una còpia local per a la classe del dia. Descarrega el que és imprescindible abans d’eixir.

  • Presentacions i vídeos que utilitzaràs.
  • PDF alternatiu dels documents.
  • Llista de grups o informació permesa per a treballar.
  • Activitat alternativa sense plataforma.
  • Adaptadors i arxius de controladors si són necessaris.
{% else %}

La sincronización no sustituye una copia local para la clase del día. Descarga lo imprescindible antes de salir.

  • Presentaciones y vídeos que vayas a utilizar.
  • PDF alternativo de los documentos.
  • Lista de grupos o información permitida para trabajar.
  • Actividad alternativa sin plataforma.
  • Adaptadores y archivos de controladores si son necesarios.
{% endif %}
