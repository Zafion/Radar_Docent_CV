{% if current_lang == 'va' %} Una llista pràctica per a arribar preparat al centre sense carregar material que probablement no necessitaràs. {% else %} Una lista práctica para llegar preparado al centro sin cargar material que probablemente no necesitarás. {% endif %}

{% if current_lang == 'va' %} Aquesta guia és orientativa. Confirma siempre con el centro qué documentación debes presentar y si existe algún procedimiento específico de incorporación. {% endif %}

{% if current_lang == 'va' %}La idea principal{% else %}La idea principal{% endif %}

{% if current_lang == 'va' %} El primer dia no necessites muntar una aula portàtil. El més important és poder identificar-te, prendre notes, consultar la informació del nomenament i adaptar-te a la manera de treballar del centre. Porta un equip lleuger i deixa les compres específiques per a després de conéixer l'horari, les aules i els recursos disponibles. {% else %} El primer día no necesitas montar un aula portátil. Lo más importante es poder identificarte, tomar notas, consultar la información del nombramiento y adaptarte a la forma de trabajar del centro. Lleva un equipo ligero y deja las compras específicas para después de conocer el horario, las aulas y los recursos disponibles. {% endif %}

🪪

{% if current_lang == 'va' %}1. Documentació i informació{% else %}1. Documentación e información{% endif %}

{% if current_lang == 'va' %}
  • DNI, NIE o document identificatiu.
  • Credencial, nomenament o justificant d'adjudicació disponible.
  • Dades de contacte del centre i nom de la persona amb qui has parlat.
  • Adreça exacta, hora d'arribada i ruta revisada amb antelació.
  • Qualsevol document que el centre t'haja demanat expressament.

Porta els documents importants també en format digital, però evita guardar dades sensibles en dispositius sense protecció.

{% else %}
  • DNI, NIE o documento identificativo.
  • Credencial, nombramiento o justificante de adjudicación disponible.
  • Datos de contacto del centro y nombre de la persona con la que has hablado.
  • Dirección exacta, hora de llegada y ruta revisada con antelación.
  • Cualquier documento que el centro te haya pedido expresamente.

Lleva los documentos importantes también en formato digital, pero evita guardar datos sensibles en dispositivos sin protección.

{% endif %}
🗂️

{% if current_lang == 'va' %}2. Material bàsic{% else %}2. Material básico{% endif %}

{% if current_lang == 'va' %}
  • Una carpeta rígida o portadocuments.
  • Un quadern o agenda per a horaris, noms i instruccions.
  • Dos bolígrafs i un llapis.
  • Un estoig menut amb el material que uses habitualment.
  • Algunes fundes transparents per a documents.

No cal portar una gran quantitat de material escolar. Primer comprova què proporciona el centre i què exigeix realment el lloc.

{% else %}
  • Una carpeta rígida o portadocumentos.
  • Un cuaderno o agenda para horarios, nombres e instrucciones.
  • Dos bolígrafos y un lápiz.
  • Un estuche pequeño con el material que utilizas habitualmente.
  • Algunas fundas transparentes para documentos.

No hace falta llevar una gran cantidad de material escolar. Primero comprueba qué proporciona el centro y qué exige realmente el puesto.

{% endif %}
🔌

{% if current_lang == 'va' %}3. Tecnologia útil{% else %}3. Tecnología útil{% endif %}

{% if current_lang == 'va' %}
  • Telèfon carregat i carregador.
  • Bateria externa si tens un desplaçament llarg.
  • Portàtil o tauleta només si saps que et resultarà útil.
  • Carregador del portàtil i adaptador HDMI o USB-C si ja en disposes.
  • Memòria USB només quan siga necessària i sense dades personals de l'alumnat.

No dones per fet que podràs connectar qualsevol dispositiu a la xarxa o als equips del centre. Pregunta abans i respecta les normes de seguretat i protecció de dades.

{% else %}
  • Teléfono cargado y cargador.
  • Batería externa si tienes un desplazamiento largo.
  • Portátil o tableta solo si sabes que te resultará útil.
  • Cargador del portátil y adaptador HDMI o USB-C si ya dispones de ellos.
  • Memoria USB solo cuando sea necesaria y sin datos personales del alumnado.

No des por hecho que podrás conectar cualquier dispositivo a la red o a los equipos del centro. Pregunta antes y respeta las normas de seguridad y protección de datos.

{% endif %}
🚗

{% if current_lang == 'va' %}4. Desplaçament i jornada{% else %}4. Desplazamiento y jornada{% endif %}

{% if current_lang == 'va' %}
  • Aigua i algun aliment fàcil de transportar.
  • Targeta de transport, combustible o aparcament revisats.
  • Una peça lleugera d'abric si no coneixes la temperatura de les aules.
  • Medicació personal que necessites durant la jornada.
  • Un marge de temps suficient per a trobar l'entrada i secretaria.
{% else %}
  • Agua y algún alimento fácil de transportar.
  • Tarjeta de transporte, combustible o aparcamiento revisados.
  • Una prenda ligera de abrigo si no conoces la temperatura de las aulas.
  • Medicación personal que necesites durante la jornada.
  • Un margen de tiempo suficiente para encontrar la entrada y secretaría.
{% endif %}

{% if current_lang == 'va' %}Criteris per a triar el material{% else %}Criterios para elegir el material{% endif %}

{% if current_lang == 'va' %}Carpeta o portadocuments{% else %}Carpeta o portadocumentos{% endif %}

{% if current_lang == 'va' %}Ha de protegir documents, cabre en la motxilla i poder-se obrir sense buidar tot el contingut.{% else %}Debe proteger documentos, caber en la mochila y poder abrirse sin vaciar todo el contenido.{% endif %}

{% if current_lang == 'va' %}Carregador i bateria externa{% else %}Cargador y batería externa{% endif %}

{% if current_lang == 'va' %}Prioritza compatibilitat, pes reduït i potència suficient per als dispositius que realment portaràs.{% else %}Prioriza compatibilidad, peso reducido y potencia suficiente para los dispositivos que realmente llevarás.{% endif %}

{% if current_lang == 'va' %}Motxilla o bossa{% else %}Mochila o bolsa{% endif %}

{% if current_lang == 'va' %}Comprova la grandària del portàtil, la comoditat en el trajecte i la protecció contra la pluja abans de valorar compartiments addicionals.{% else %}Comprueba el tamaño del portátil, la comodidad en el trayecto y la protección frente a la lluvia antes de valorar compartimentos adicionales.{% endif %}

{% if current_lang == 'va' %}Adaptadors{% else %}Adaptadores{% endif %}

{% if current_lang == 'va' %}És millor un adaptador senzill i compatible amb el teu equip que un hub gran amb connexions que no utilitzaràs.{% else %}Es mejor un adaptador sencillo y compatible con tu equipo que un hub grande con conexiones que no utilizarás.{% endif %}
