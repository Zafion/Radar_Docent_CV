{% if current_lang == 'va' %}Connexió a pantalles i projectors{% else %}Conexión a pantallas y proyectores{% endif %}

{% if current_lang == 'va' %}

Els centres poden tindre projectors, monitors o pissarres digitals de generacions diferents. El primer pas és identificar les eixides del teu ordinador i les entrades que utilitza el centre.

  • HDMI: és la connexió més habitual per a imatge i so.
  • USB-C: no tots els ports USB-C transmeten vídeo; comprova les especificacions del dispositiu.
  • DisplayPort o Mini DisplayPort: apareixen en alguns equips i monitors.
  • VGA: encara pot trobar-se en instal·lacions antigues i només transmet imatge.

Un adaptador o concentrador pot resoldre diverses connexions, però convé provar-lo abans d'una classe important. Porta també una còpia local de la presentació i, quan siga possible, una versió en PDF.

No connectes un adaptador desconegut per primera vegada just abans d'una sessió. Prova imatge, so, resolució i reproducció de vídeo amb antelació.

{% else %}

Los centros pueden tener proyectores, monitores o pizarras digitales de generaciones diferentes. El primer paso es identificar las salidas de tu ordenador y las entradas que utiliza el centro.

  • HDMI: es la conexión más habitual para imagen y sonido.
  • USB-C: no todos los puertos USB-C transmiten vídeo; comprueba las especificaciones del dispositivo.
  • DisplayPort o Mini DisplayPort: aparecen en algunos equipos y monitores.
  • VGA: todavía puede encontrarse en instalaciones antiguas y solo transmite imagen.

Un adaptador o concentrador puede resolver varias conexiones, pero conviene probarlo antes de una clase importante. Lleva también una copia local de la presentación y, cuando sea posible, una versión en PDF.

No conectes un adaptador desconocido por primera vez justo antes de una sesión. Prueba imagen, sonido, resolución y reproducción de vídeo con antelación.

Un escàner dedicat pot tindre sentit quan digitalitzes moltes pàgines de manera repetida, necessites alimentació automàtica o vols un resultat homogeni. Un escàner portàtil només compensa si la mobilitat és una necessitat real.

  • Exporta preferentment a PDF quan el document té diverses pàgines.
  • Utilitza noms d'arxiu descriptius i una estructura de carpetes coherent.
  • Comprova l'orientació, els marges i l'ordre de les pàgines.
  • Evita digitalitzar o guardar dades personals de l'alumnat en aplicacions no autoritzades.
{% else %}

Para un uso ocasional, la cámara del teléfono y una aplicación de escaneo pueden ser suficientes. Busca buena luz, coloca el documento plano y revisa que el texto sea legible antes de eliminar el original.

Un escáner dedicado puede tener sentido cuando digitalizas muchas páginas de forma repetida, necesitas alimentación automática o quieres un resultado homogéneo. Un escáner portátil solo compensa si la movilidad es una necesidad real.

  • Exporta preferentemente a PDF cuando el documento tiene varias páginas.
  • Utiliza nombres de archivo descriptivos y una estructura de carpetas coherente.

{% if current_lang == 'va' %}Bateria i alimentació{% else %}Batería y alimentación{% endif %}

{% if current_lang == 'va' %}
  • Carregador principal: porta'l quan no saps si tindràs accés a un endoll durant la jornada.
  • Segon carregador: és útil si treballes habitualment en dos llocs i vols evitar oblits.
  • Bateria externa: adequada per al telèfon, la tauleta o alguns portàtils compatibles, sempre que tinga prou potència.
  • Cable curt de reserva: ocupa poc i resol fallades o oblits freqüents.
  • Regleta compacta: pot ajudar en espais amb pocs endolls, però només si està en bon estat i el centre permet utilitzar-la.

No deixes bateries externes exposades a temperatures altes dins del vehicle. Retira qualsevol carregador, cable o bateria que presente deformacions, olor estranya o sobrecalfament.

{% else %}
  • Cargador principal: llévalo cuando no sabes si tendrás acceso a un enchufe durante la jornada.
  • Segundo cargador: es útil si trabajas habitualmente en dos lugares y quieres evitar olvidos.
  • Batería externa: adecuada para el teléfono, la tableta o algunos portátiles compatibles, siempre que tenga suficiente potencia.
  • Cable corto de reserva: ocupa poco y resuelve fallos u olvidos frecuentes.

{% if current_lang == 'va' %}Arxius, còpies de seguretat i treball sense connexió{% else %}Archivos, copias de seguridad y trabajo sin conexión{% endif %}

{% if current_lang == 'va' %}

La millor protecció no és portar moltes memòries, sinó saber on està la còpia principal i com recuperar-la. Utilitza un sistema coherent:

  1. Una carpeta principal ordenada per cursos, grups o projectes.
  2. Una còpia de seguretat separada i actualitzada.
  3. Sincronització només dels arxius que necessites en diversos dispositius.
  4. Versions locals dels materials imprescindibles per a la classe.
  5. Una exportació en PDF de presentacions o documents que puguen canviar de format.

Una memòria USB pot ser una còpia de transport, però no ha de ser l'únic lloc on guardes el material. Xifra o evita portar informació sensible, i no connectes dispositius desconeguts als equips del centre.

{% else %}

La mejor protección no es llevar muchas memorias, sino saber dónde está la copia principal y cómo recuperarla. Utiliza un sistema coherente:

  1. Una carpeta principal ordenada por cursos, grupos o proyectos.
  2. Una copia de seguridad separada y actualizada.
  3. Sincronización solo de los archivos que necesitas en varios dispositivos.
  4. Versiones locales de los materiales imprescindibles para la clase.
  5. Una exportación en PDF de presentaciones o documentos que puedan cambiar de formato.

Una memoria USB puede ser una copia de transporte, pero no debe ser el único lugar donde guardas el material. Cifra o evita llevar información sensible, y no conectes dispositivos desconocidos a los equipos del centro.

{% endif %}
