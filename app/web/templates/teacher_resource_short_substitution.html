{% if current_lang == 'va' %}Abans d'acudir al centre{% else %}Antes de acudir al centro{% endif %}

{% if current_lang == 'va' %}

Reunix únicament la informació que pugues confirmar. La duració prevista pot canviar, per la qual cosa convé preparar una incorporació útil tant per a uns dies com per a diverses setmanes.

Anota l'adreça exacta, l'hora d'entrada, el nom del centre, un telèfon de contacte i el mitjà de transport. Calcula marge per a aparcar, localitzar consergeria i completar els tràmits inicials.

  • Document identificatiu i documentació sol·licitada.
  • Bolígraf, llibreta o sistema de notes.
  • Aigua i una opció senzilla de menjar.
  • Carregador i adaptadors només si portaràs dispositiu.
  • Una carpeta buida per a horaris i documentació.
{% else %}

Reúne únicamente la información que puedas confirmar. La duración prevista puede cambiar, por lo que conviene preparar una incorporación útil tanto para unos días como para varias semanas.

Anota la dirección exacta, la hora de entrada, el nombre del centro, un teléfono de contacto y el medio de transporte. Calcula margen para aparcar, localizar conserjería y completar los trámites iniciales.

  • Documento identificativo y documentación solicitada.
  • Bolígrafo, libreta o sistema de notas.
  • Agua y una opción sencilla de comida.
  • Cargador y adaptadores solo si llevarás dispositivo.
  • Una carpeta vacía para horarios y documentación.
{% endif %}

{% if current_lang == 'va' %}La informació mínima de la primera hora{% else %}La información mínima de la primera hora{% endif %}

{% if current_lang == 'va' %}

No intentes memoritzar-ho tot. Crea un full de referència breu amb les dades que condicionen el dia.

  • Horari, aules i grups.
  • Persona de referència de l’equip directiu o departament.
  • Guàrdies, patis, reunions i tasques no lectives.
  • Normes d’accés, claus i ús d’espais.
  • Plataforma educativa i procediment per a registrar assistència.
  • Informació imprescindible sobre adaptacions o suports, pels canals autoritzats.
  • Material que va deixar preparat la persona substituïda.
{% else %}

No intentes memorizarlo todo. Crea una hoja de referencia breve con los datos que condicionan el día.

  • Horario, aulas y grupos.
  • Persona de referencia del equipo directivo o departamento.
  • Guardias, recreos, reuniones y tareas no lectivas.
  • Normas de acceso, llaves y uso de espacios.
  • Plataforma educativa y procedimiento para registrar asistencia.
  • Información imprescindible sobre adaptaciones o apoyos, por los canales autorizados.
  • Material que dejó preparado la persona sustituida.
{% endif %}

{% if current_lang == 'va' %}Planifica el primer dia amb marge{% else %}Planifica el primer día con margen{% endif %}

{% if current_lang == 'va' %}

El primer objectiu és conéixer el ritme del grup i comprovar quin treball pot continuar. Evita introduir canvis grans abans d’entendre les normes i la programació existent.

Prepara una activitat adaptable que permeta observar coneixements previs, hàbits de treball i necessitats del grup sense dependre d’una tecnologia concreta.

  • Presentació breu i explicació de com es treballarà durant la substitució.
  • Revisió del punt exacte del temari o projecte.
  • Activitat de continuïtat o diagnòstic senzill.
  • Registre de dubtes que hages de consultar al departament.
  • Alternativa sense connexió per si falla la plataforma o el projector.
{% else %}

El primer objetivo es conocer el ritmo del grupo y comprobar qué trabajo puede continuar. Evita introducir cambios grandes antes de entender las normas y la programación existente.

Prepara una actividad adaptable que permita observar conocimientos previos, hábitos de trabajo y necesidades del grupo sin depender de una tecnología concreta.

  • Presentación breve y explicación de cómo se trabajará durante la sustitución.
  • Revisión del punto exacto del temario o proyecto.
  • Actividad de continuidad o diagnóstico sencillo.
  • Registro de dudas que debas consultar al departamento.
  • Alternativa sin conexión por si falla la plataforma o el proyector.
{% endif %}

{% if current_lang == 'va' %}Crea un registre de continuïtat{% else %}Crea un registro de continuidad{% endif %}

{% if current_lang == 'va' %}

Dedica uns minuts després de cada sessió a deixar constància del que és important. Un registre breu i constant evita dependre de la memòria.

  • Data, grup i contingut treballat.
  • Tasques proposades i data prevista de lliurament.
  • Incidències rellevants comunicades pel canal corresponent.
  • Material pendent de corregir o retornar.
  • Canvis respecte de la planificació inicial.
  • Pròxim pas recomanat per a cada grup.
{% else %}

Dedica unos minutos después de cada sesión a dejar constancia de lo importante. Un registro breve y constante evita depender de la memoria.

  • Fecha, grupo y contenido trabajado.
  • Tareas propuestas y fecha prevista de entrega.
  • Incidencias relevantes comunicadas por el canal correspondiente.
  • Material pendiente de corregir o devolver.
  • Cambios respecto a la planificación inicial.
  • Próximo paso recomendado para cada grupo.
{% endif %}

Crea una carpeta específica para la sustitución y evita mezclarla con archivos personales o de otros centros.

  • 00_Horario_y_contactos
  • 01_Programacion_y_material_recibido
  • 02_Material_preparado
  • 03_Entregas_y_correcciones

Usa únicamente cuentas, plataformas y sistemas autorizados por el centro para tratar información del alumnado.

{% if current_lang == 'va' %}Coordina’t sense multiplicar missatges{% else %}Coordínate sin multiplicar mensajes{% endif %}

{% if current_lang == 'va' %}

Identifica una persona de referència i agrupa els dubtes. És més eficient presentar una llista ordenada que interrompre diverses vegades per qüestions menudes.

  • Dubtes que bloquegen una classe immediata.
  • Decisions que afecten a avaluació o lliuraments.
  • Necessitats específiques de determinats grups.
  • Accés a espais, materials o plataformes.
  • Dates de reunions o activitats ja programades.
{% else %}

Identifica una persona de referencia y agrupa las dudas. Es más eficiente presentar una lista ordenada que interrumpir varias veces por cuestiones pequeñas.

  • Dudas que bloquean una clase inmediata.
  • Decisiones que afectan a evaluación o entregas.
  • Necesidades específicas de determinados grupos.
  • Acceso a espacios, materiales o plataformas.
  • Fechas de reuniones o actividades ya programadas.
{% endif %}

{% if current_lang == 'va' %}Prepara el tancament des del primer dia{% else %}Prepara el cierre desde el primer día{% endif %}

{% if current_lang == 'va' %}

Encara que no conegues la data exacta de finalització, guarda la informació de manera que una altra persona puga comprendre-la sense una explicació llarga.

  • Resum per grup.
  • Continguts impartits i pròxims continguts.
  • Tasques pendents i correccions realitzades.
  • Material creat i ubicació dels arxius.
  • Incidències ja comunicades.
  • Claus, dispositius o recursos que hages de retornar.
{% else %}

Aunque no conozcas la fecha exacta de finalización, guarda la información de forma que otra persona pueda comprenderla sin una explicación larga.

  • Resumen por grupo.
  • Contenidos impartidos y próximos contenidos.
  • Tareas pendientes y correcciones realizadas.
  • Material creado y ubicación de los archivos.
  • Incidencias ya comunicadas.
  • Llaves, dispositivos o recursos que debas devolver.
{% endif %}

{% if current_lang == 'va' %}Criteri final{% else %}Criterio final{% endif %}

{% if current_lang == 'va' %}

Comença amb un sistema senzill, comprova si realment et facilita el treball i ajusta’l quan canvien el centre, l’horari o les necessitats. Una organització útil ha de reduir errors i decisions repetides, no crear més manteniment.

{% else %}

Empieza con un sistema sencillo, comprueba si realmente te facilita el trabajo y ajústalo cuando cambien el centro, el horario o las necesidades. Una organización útil debe reducir errores y decisiones repetidas, no crear más mantenimiento.

{% endif %}
