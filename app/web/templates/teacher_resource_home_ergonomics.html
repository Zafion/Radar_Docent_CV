No necesitas un despacho perfecto, pero sí una postura sostenible, luz suficiente y un sistema que reduzca movimientos repetidos y acumulación de materiales. {% endif %}

{% if current_lang == 'va' %}Comença per observar com treballes{% else %}Empieza por observar cómo trabajas{% endif %}

{% if current_lang == 'va' %}

Abans de comprar res, registra durant diversos dies quines molèsties o interrupcions apareixen i quines tasques ocupen més temps.

  • Coll inclinat cap a la pantalla.
  • Muscles elevats en escriure.
  • Canells doblegats o recolzats en una vora dura.
  • Reflexos en la pantalla.
  • Documents que obliguen a girar-se constantment.
  • Cables i materials que envaïxen la superfície.
  • Sessions massa llargues sense canviar de postura.
{% else %}

Antes de comprar nada, registra durante varios días qué molestias o interrupciones aparecen y qué tareas ocupan más tiempo.

  • Cuello inclinado hacia la pantalla.
  • Hombros elevados al escribir.
  • Muñecas dobladas o apoyadas en un borde duro.
  • Reflejos en la pantalla.
  • Documentos que obligan a girarse constantemente.
  • Cables y materiales que invaden la superficie.
  • Sesiones demasiado largas sin cambiar de postura.
{% endif %}

{% if current_lang == 'va' %}Ajusta primer cadira, taula i pantalla{% else %}Ajusta primero silla, mesa y pantalla{% endif %}

{% if current_lang == 'va' %}

Busca una posició estable que pugues mantindre sense tensió. Les mesures exactes depenen del teu cos i del mobiliari, per la qual cosa importa més la relació entre els elements que una xifra universal.

  • Peus recolzats a terra o en una superfície estable.
  • Esquena recolzada sense avançar el cap.
  • Colzes prop del cos.
  • Teclat i ratolí a una altura que no eleve els muscles.
  • Pantalla centrada i a una distància còmoda.
  • Part superior de la pantalla aproximadament a l’altura dels ulls, adaptant-la a les teues ulleres i postura.
{% else %}

Busca una posición estable que puedas mantener sin tensión. Las medidas exactas dependen de tu cuerpo y del mobiliario, por lo que importa más la relación entre los elementos que una cifra universal.

  • Pies apoyados en el suelo o en una superficie estable.
  • Espalda apoyada sin adelantar la cabeza.
  • Codos cerca del cuerpo.
  • Teclado y ratón a una altura que no eleve los hombros.
  • Pantalla centrada y a una distancia cómoda.
  • Parte superior de la pantalla aproximadamente a la altura de los ojos, adaptándola a tus gafas y postura.
{% endif %}

{% if current_lang == 'va' %}Si treballes amb portàtil{% else %}Si trabajas con portátil{% endif %}

{% if current_lang == 'va' %}

El portàtil obliga a triar entre una pantalla baixa o un teclat alt. Per a sessions llargues, elevar-lo i usar teclat i ratolí externs sol permetre una postura més neutral.

  • Suport estable o elevació segura.
  • Teclat extern de grandària suficient.
  • Ratolí que no obligue a apretar la mà.
  • Espai per a recolzar avantbraços sense bloquejar el moviment.
  • Carregador col·locat perquè el cable no creue la zona de treball.
{% else %}

El portátil obliga a elegir entre una pantalla baja o un teclado alto. Para sesiones largas, elevarlo y usar teclado y ratón externos suele permitir una postura más neutral.

  • Soporte estable o elevación segura.
  • Teclado externo de tamaño suficiente.
  • Ratón que no obligue a apretar la mano.
  • Espacio para apoyar antebrazos sin bloquear el movimiento.
  • Cargador colocado para que el cable no cruce la zona de trabajo.
{% endif %}

{% if current_lang == 'va' %}Il·luminació sense reflexos{% else %}Iluminación sin reflejos{% endif %}

{% if current_lang == 'va' %}

Combina llum general amb una llum de tasca per a paper o escriptura. Evita col·locar una finestra o llum intensa directament davant o darrere de la pantalla.

  • Col·locar la pantalla perpendicular a la finestra quan siga possible.
  • Ajustar la brillantor a la llum de l’habitació.
  • Il·luminar els documents sense crear ombres de la mà.
  • Netejar la pantalla i les ulleres per a reduir esforç visual.
  • Augmentar la grandària del text abans que acostar massa el cap.
{% else %}

Combina luz general con una luz de tarea para papel o escritura. Evita colocar una ventana o lámpara intensa directamente delante o detrás de la pantalla.

  • Colocar la pantalla perpendicular a la ventana cuando sea posible.
  • Ajustar el brillo a la luz de la habitación.
  • Iluminar los documentos sin crear sombras de la mano.
  • Limpiar la pantalla y las gafas para reducir esfuerzo visual.
  • Aumentar tamaño de texto antes que acercar demasiado la cabeza.
{% endif %}

{% if current_lang == 'va' %}Dividix la superfície en zones{% else %}Divide la superficie en zonas{% endif %}

{% if current_lang == 'va' %}

Fins i tot una taula xicoteta funciona millor quan cada zona té una finalitat.

  • Zona central per a teclat, ratolí i tasca actual.
  • Zona lateral per a documents de consulta.
  • Safata o carpeta per a material pendent.
  • Lloc fix per a bolígrafs, carregadors i adaptadors.
  • Àrea fora de la taula per a arxiu i materials poc freqüents.
{% else %}

Incluso una mesa pequeña funciona mejor cuando cada zona tiene una finalidad.

  • Zona central para teclado, ratón y tarea actual.
  • Zona lateral para documentos de consulta.
  • Bandeja o carpeta para material pendiente.
  • Lugar fijo para bolígrafos, cargadores y adaptadores.
  • Área fuera de la mesa para archivo y materiales poco frecuentes.
{% endif %}

{% if current_lang == 'va' %}Alterna tasques i postures{% else %}Alterna tareas y posturas{% endif %}

{% if current_lang == 'va' %}

La millor postura deixa de ser bona si es manté massa temps. Canvia d’activitat i alça’t amb regularitat.

  • Agrupar impressions o escanejos per a alçar-te.
  • Fer telefonades o lectures breus dret si és còmode.
  • Alternar correcció en pantalla amb planificació en paper.
  • Programar pauses curtes abans de notar fatiga intensa.
  • Moure coll, muscles, mans i cames suaument.

Si apareix dolor persistent, formigueig o pèrdua de força, consulta un professional sanitari; no intentes resoldre-ho només amb accessoris.

{% else %}

La mejor postura deja de ser buena si se mantiene demasiado tiempo. Cambia de actividad y levántate con regularidad.

  • Agrupar impresiones o escaneos para levantarte.
  • Realizar llamadas o lecturas breves de pie si es cómodo.
  • Alternar corrección en pantalla con planificación en papel.
  • Programar pausas cortas antes de notar fatiga intensa.
  • Mover cuello, hombros, manos y piernas suavemente.

Si aparece dolor persistente, hormigueo o pérdida de fuerza, consulta a un profesional sanitario; no intentes resolverlo solo con accesorios.

{% endif %}

{% if current_lang == 'va' %}Reduïx soroll i distraccions{% else %}Reduce ruido y distracciones{% endif %}

{% if current_lang == 'va' %}

Un espai còmode també necessita límits. Prepara sessions amb una tasca concreta i tanca el que no intervinga en ella.

  • Silenciar notificacions no urgents.
  • Usar un perfil de navegador professional.
  • Deixar el telèfon fora de l’abast si no és necessari.
  • Utilitzar auriculars només quan siguen còmodes i segurs.
  • Definir una hora de finalització per a evitar allargar la jornada indefinidament.
{% else %}

Un espacio cómodo también necesita límites. Prepara sesiones con una tarea concreta y cierra lo que no intervenga en ella.

  • Silenciar notificaciones no urgentes.
  • Usar un perfil de navegador profesional.
  • Dejar el teléfono fuera del alcance si no es necesario.
  • Utilizar auriculares solo cuando sean cómodos y seguros.
  • Definir una hora de finalización para evitar alargar la jornada indefinidamente.
{% endif %}

{% if current_lang == 'va' %}Orde de millora amb pressupost limitat{% else %}Orden de mejora con presupuesto limitado{% endif %}

{% if current_lang == 'va' %}

No és necessari comprar-ho tot alhora. Corregix primer el problema que més hores o molèsties genera.

  • Ajustar amb el que ja tens.
  • Millorar l’altura de pantalla.
  • Afegir teclat i ratolí si uses portàtil durant hores.
  • Millorar la il·luminació.
  • Revisar cadira o suport de peus.
  • Afegir emmagatzematge per a aclarir la taula.
  • Valorar una segona pantalla només si millora una tasca habitual.
{% else %}

No es necesario comprar todo a la vez. Corrige primero el problema que más horas o molestias genera.

  • Ajustar con lo que ya tienes.
  • Mejorar la altura de pantalla.
  • Añadir teclado y ratón si usas portátil durante horas.
  • Mejorar la iluminación.
  • Revisar silla o apoyo de pies.
  • Añadir almacenamiento para despejar la mesa.
  • Valorar una segunda pantalla solo si mejora una tarea habitual.
{% endif %}

  • Teclado y ratón no obligan a elevar hombros.
