{% if current_lang == 'va' %} Kit pràctic per a docents itinerants {% else %} Kit práctico para docentes itinerantes {% endif %}

{% if current_lang == 'va' %} Una manera lleugera i modular d'organitzar el material quan canvies d'aula, d'edifici o de centre durant la jornada. {% else %} Una forma ligera y modular de organizar el material cuando cambias de aula, edificio o centro durante la jornada. {% endif %}

Ha de resoldre les necessitats habituals, poder-se adaptar a cada dia i continuar sent còmode després de diverses hores de desplaçaments. {% else %} Un buen kit itinerante no intenta cubrir cualquier situación. Debe resolver las necesidades habituales, poder adaptarse a cada día y seguir siendo cómodo después de varias horas de desplazamientos. {% endif %}

{% if current_lang == 'va' %}Què significa treballar de manera itinerant{% else %}Qué significa trabajar de forma itinerante{% endif %}

{% if current_lang == 'va' %}

No tots els docents itinerants tenen la mateixa rutina. Pots canviar d'aula en cada sessió, treballar en edificis separats, atendre diversos centres o compartir espais i materials amb altres professionals.

Abans de preparar el kit, identifica els desplaçaments reals:

  • Quantes vegades canvies d'espai durant una jornada normal.
  • Quina distància recorres a peu i si hi ha escales.
  • Si pots deixar material de manera segura en algun centre.
  • Quins dispositius i connexions necessites en cada ubicació.
  • Quin material és imprescindible en totes les sessions i quin és ocasional.
{% else %}

No todos los docentes itinerantes tienen la misma rutina. Puedes cambiar de aula en cada sesión, trabajar en edificios separados, atender varios centros o compartir espacios y materiales con otros profesionales.

Antes de preparar el kit, identifica los desplazamientos reales:

  • Cuántas veces cambias de espacio durante una jornada normal.
  • Qué distancia recorres a pie y si hay escaleras.
  • Si puedes dejar material de forma segura en algún centro.
  • Qué dispositivos y conexiones necesitas en cada ubicación.
  • Qué material es imprescindible en todas las sesiones y cuál es ocasional.
{% endif %}

{% if current_lang == 'va' %}Tres nivells de kit segons la jornada{% else %}Tres niveles de kit según la jornada{% endif %}

1️⃣

{% if current_lang == 'va' %}Kit mínim{% else %}Kit mínimo{% endif %}

{% if current_lang == 'va' %}

Per a dies amb material disponible al centre o poques sessions.

  • Identificació, claus i telèfon.
  • Carpeta del dia.
  • Estoig menut.
  • Aigua i objectes personals.
{% else %}

Para días con material disponible en el centro o pocas sesiones.

  • Identificación, llaves y teléfono.
  • Carpeta del día.
  • Estuche pequeño.
  • Agua y objetos personales.
{% endif %}
2️⃣

{% if current_lang == 'va' %}Kit digital{% else %}Kit digital{% endif %}

{% if current_lang == 'va' %}

Afig només el necessari quan treballes amb portàtil o tauleta.

  • Dispositiu amb funda.
  • Carregador i cable.
  • Adaptador de pantalla comprovat.
  • Ratolí compacte si realment l'utilitzes.
{% else %}

Añade solo lo necesario cuando trabajas con portátil o tableta.

  • Dispositivo con funda.
  • Cargador y cable.
  • Adaptador de pantalla comprobado.
  • Ratón compacto si realmente lo utilizas.
{% endif %}
3️⃣

{% if current_lang == 'va' %}Kit de sessió específica{% else %}Kit de sesión específica{% endif %}

{% if current_lang == 'va' %}

Un mòdul independent per al material que només necessites en una classe concreta.

  • Fitxes o material manipulatiu.
  • Retoladors o recursos especials.
  • Cables o dispositius poc habituals.
  • Una etiqueta amb el grup o la sessió.
{% else %}

Un módulo independiente para el material que solo necesitas en una clase concreta.

  • Fichas o material manipulativo.
  • Rotuladores o recursos especiales.
  • Cables o dispositivos poco habituales.
  • Una etiqueta con el grupo o la sesión.
{% endif %}

{% if current_lang == 'va' %}Què convé duplicar{% else %}Qué conviene duplicar{% endif %}

{% if current_lang == 'va' %}

Quan treballes habitualment en dos centres, pot ser més còmode deixar alguns objectes econòmics i no personals en cada ubicació, sempre que disposes d'un espai segur i autoritzat.

  • Bolígrafs, llapis i retoladors de pissarra.
  • Carregadors senzills, si són compatibles i poden quedar guardats.
  • Material d'higiene o una botella buida.
  • Carpetes o fundes per a documents interns de cada centre.

No deixes documentació personal, dispositius, claus, medicació ni informació sensible en espais compartits.

{% else %}

Cuando trabajas habitualmente en dos centros, puede resultar más cómodo dejar algunos objetos económicos y no personales en cada ubicación, siempre que dispongas de un espacio seguro y autorizado.

  • Bolígrafos, lápices y rotuladores de pizarra.
  • Cargadores sencillos, si son compatibles y pueden quedar guardados.
  • Material de higiene o una botella vacía.
  • Carpetas o fundas para documentos internos de cada centro.

No dejes documentación personal, dispositivos, llaves, medicación ni información sensible en espacios compartidos.

{% endif %}

{% if current_lang == 'va' %}Organitza el kit per dies, no per setmanes{% else %}Organiza el kit por días, no por semanas{% endif %}

{% if current_lang == 'va' %}
  1. Revisa l'horari del dia següent.
  2. Parteix del kit mínim.
  3. Afig el mòdul digital només si el necessites.
  4. Incorpora el material específic de cada sessió.
  5. Retira papers, cables i objectes que ja no utilitzaràs.

Una revisió de dos minuts al final de la jornada evita transportar durant tota la setmana materials que només s'utilitzen un dia.

{% else %}
  1. Revisa el horario del día siguiente.
  2. Parte del kit mínimo.
  3. Añade el módulo digital solo si lo necesitas.
  4. Incorpora el material específico de cada sesión.
  5. Retira papeles, cables y objetos que ya no utilizarás.

Una revisión de dos minutos al final de la jornada evita transportar durante toda la semana materiales que solo se utilizan un día.

{% endif %}

{% if current_lang == 'va' %}Seguretat i informació sensible{% else %}Seguridad e información sensible{% endif %}

{% if current_lang == 'va' %}
  • No guardes dades personals de l'alumnat en memòries USB sense protecció.
  • Bloqueja el portàtil o la tauleta quan t'allunyes, encara que siga durant pocs minuts.
  • No deixes el kit complet visible dins del cotxe.
  • Identifica cables i accessoris sense escriure dades personals innecessàries.
  • Utilitza els sistemes i procediments autoritzats pel centre per a compartir documentació.
{% else %}
  • No guardes datos personales del alumnado en memorias USB sin protección.
  • Bloquea el portátil o la tableta cuando te alejes, aunque sea durante pocos minutos.
  • No dejes el kit completo visible dentro del coche.
  • Identifica cables y accesorios sin escribir datos personales innecesarios.
  • Utiliza los sistemas y procedimientos autorizados por el centro para compartir documentación.
{% endif %}
