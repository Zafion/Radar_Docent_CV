{% if current_lang == 'va' %}Comença amb un únic registre mestre{% else %}Empieza con un único registro maestro{% endif %}

{% if current_lang == 'va' %}

Abans de crear carpetes, prepara una taula o full de càlcul que actue com a índex de tots els procediments. Cada fila representa una convocatòria, una actualització de borsa o un tràmit concret.

Com a mínim, anota:

  • Nom breu del procediment.
  • Administració o organisme responsable.
  • Especialitat, cos o borsa afectada.
  • Data de publicació.
  • Data i hora límit.
  • Enllaç a la font oficial.
  • Estat: pendent, en preparació, presentat, esmenat o tancat.
  • Ubicació de la carpeta digital corresponent.
  • Número de registre o justificant, quan existisca.

Utilitza sempre la publicació oficial per a confirmar terminis, requisits i canals de presentació. El registre mestre és una ajuda d'organització, no la font administrativa.

{% else %}

  • Ubicación de la carpeta digital correspondiente.

{% if current_lang == 'va' %}Controla els terminis amb tres recordatoris{% else %}Controla los plazos con tres recordatorios{% endif %}

{% if current_lang == 'va' %}

No depengues d'un únic avís el dia que acaba el termini. Per a cada tràmit important, crea tres recordatoris:

  1. Inici del treball: quan convé llegir les bases i reunir la documentació.
  2. Revisió: almenys uns dies abans per a comprovar requisits, arxius i formularis.
  3. Límit intern: una data anterior al termini oficial per a presentar sense presses.

En el registre mestre, diferencia clarament la data oficial de la teua data interna. Si hi ha una hora límit, anota-la també.

{% else %}

No dependas de un único aviso el día que termina el plazo. Para cada trámite importante, crea tres recordatorios:

  1. Inicio del trabajo: cuándo conviene leer las bases y reunir la documentación.
  2. Revisión: al menos unos días antes para comprobar requisitos, archivos y formularios.
  3. Límite interno: una fecha anterior al plazo oficial para presentar sin prisas.

En el registro maestro, diferencia claramente la fecha oficial de tu fecha interna. Si existe una hora límite, anótala también.

{% endif %}

{% if current_lang == 'va' %}Crea un inventari de mèrits{% else %}Crea un inventario de méritos{% endif %}

{% if current_lang == 'va' %}

La carpeta de mèrits guarda els certificats; l'inventari explica què tens. En una taula separada, registra:

  • Nom del mèrit.
  • Entitat emissora.
  • Data d'inici i finalització.
  • Duració en hores o crèdits, quan conste.
  • Categoria aproximada segons el procediment.
  • Nom i ubicació de l'arxiu acreditatiu.
  • Observacions: firma, codi de verificació, traducció o document pendent.

No dones per fet que un mèrit serà baremable en qualsevol convocatòria. Els criteris poden variar; comprova sempre les bases del procediment concret.

{% else %}

La carpeta de méritos guarda los certificados; el inventario explica qué tienes. En una tabla separada, registra:

  • Nombre del mérito.
  • Entidad emisora.
  • Fecha de inicio y finalización.
  • Duración en horas o créditos, cuando conste.
  • Categoría aproximada según el procedimiento.
  • Nombre y ubicación del archivo acreditativo.
  • Observaciones: firma, código de verificación, traducción o documento pendiente.

No des por hecho que un mérito será baremable en cualquier convocatoria. Los criterios pueden variar; comprueba siempre las bases del procedimiento concreto.

{% endif %}

{% if current_lang == 'va' %}Guarda el justificant al mateix moment{% else %}Guarda el justificante en el mismo momento{% endif %}

{% if current_lang == 'va' %}

Un tràmit no està complet només perquè el formulari haja desaparegut de la pantalla. En acabar:

  1. Descarrega el justificant o rebut de registre.
  2. Comprova que identifica el procediment i la persona interessada.
  3. Revisa la data, hora i número de registre.
  4. Guarda'l en la carpeta de la convocatòria.
  5. Anota el número en el registre mestre.
  6. Conserva també la sol·licitud exacta que s'ha presentat, quan siga possible.

Si el procediment permet esmenes, crea una subcarpeta específica amb la notificació, els documents aportats i el nou justificant.

{% else %}

Un trámite no está completo solo porque el formulario haya desaparecido de la pantalla. Al terminar:

  1. Descarga el justificante o recibo de registro.
  2. Comprueba que identifica el procedimiento y a la persona interesada.
  3. Revisa la fecha, hora y número de registro.
  4. Guárdalo en la carpeta de la convocatoria.
  5. Anota el número en el registro maestro.
  6. Conserva también la solicitud exacta que se ha presentado, cuando sea posible.

Si el procedimiento permite subsanaciones, crea una subcarpeta específica con la notificación, los documentos aportados y el nuevo justificante.

{% endif %}

{% if current_lang == 'va' %}Paper: conserva només el que aporta valor{% else %}Papel: conserva solo lo que aporta valor{% endif %}

{% if current_lang == 'va' %}

No cal imprimir cada PDF. Reserva l'arxiu físic per als originals que necessites conservar, còpies compulsades, documents que hages de presentar presencialment o materials que revises millor en paper.

Una organització senzilla pot utilitzar:

  • Un arxivador per a titulacions i certificats permanents.
  • Separadors per tipus de mèrit.
  • Una carpeta temporal per al procediment actiu.
  • Fundes només per a originals o documents delicats.

Quan finalitze una convocatòria, retira duplicats, esborranys i còpies que ja no siguen necessàries.

{% else %}

No es necesario imprimir cada PDF. Reserva el archivo físico para los originales que necesites conservar, copias compulsadas, documentos que debas presentar presencialmente o materiales que revises mejor en papel.

Una organización sencilla puede utilizar:

  • Un archivador para titulaciones y certificados permanentes.
  • Separadores por tipo de mérito.
  • Una carpeta temporal para el procedimiento activo.
  • Fundas solo para originales o documentos delicados.

Cuando termine una convocatoria, retira duplicados, borradores y copias que ya no sean necesarias.

{% endif %}

{% if current_lang == 'va' %}Còpies de seguretat i protecció de dades{% else %}Copias de seguridad y protección de datos{% endif %}

{% if current_lang == 'va' %}
  • Mantín una còpia principal ordenada i almenys una còpia de seguretat separada.
  • No depengues únicament d'una memòria USB o del disc d'un portàtil.
  • Protegeix els dispositius amb contrasenya i bloqueig automàtic.
  • Evita compartir carpetes completes quan només necessites enviar un document.
  • Revisa els permisos dels serveis en el núvol que utilitzes.
  • No guardes contrasenyes, certificats digitals o claus privades juntament amb còpies accessibles dels documents personals.

La còpia de seguretat ha de poder recuperar-se. Comprova de tant en tant que els arxius s'obrin i que la còpia està actualitzada.

{% else %}
  • Mantén una copia principal ordenada y al menos una copia de seguridad separada.
  • No dependas únicamente de una memoria USB o del disco de un portátil.
  • Protege los dispositivos con contraseña y bloqueo automático.
  • Evita compartir carpetas completas cuando solo necesites enviar un documento.
  • Revisa los permisos de los servicios en la nube que utilices.
  • No guardes contraseñas, certificados digitales o claves privadas junto a copias accesibles de los documentos personales.

La copia de seguridad debe poder recuperarse. Comprueba de vez en cuando que los archivos se abren y que la copia está actualizada.

{% endif %}

{% if current_lang == 'va' %}Revisió mensual de quinze minuts{% else %}Revisión mensual de quince minutos{% endif %}

{% if current_lang == 'va' %}
  1. Comprova si hi ha convocatòries o terminis pròxims.
  2. Actualitza l'estat dels procediments tancats.
  3. Afig els nous cursos, certificats o serveis prestats.
  4. Revisa documents que caduquen o que convé renovar.
  5. Elimina duplicats i mou esborranys antics a una carpeta temporal.
  6. Actualitza la còpia de seguretat.

Una revisió curta i regular és més efectiva que reorganitzar tot l'arxiu quan s'obri una convocatòria important.

{% else %}
  1. Comprueba si existen convocatorias o plazos próximos.
  2. Actualiza el estado de los procedimientos cerrados.
  3. Añade los nuevos cursos, certificados o servicios prestados.
  4. Revisa documentos que caducan o que conviene renovar.
  5. Elimina duplicados y mueve borradores antiguos a una carpeta temporal.
  6. Actualiza la copia de seguridad.

Una revisión corta y regular es más efectiva que reorganizar todo el archivo cuando se abre una convocatoria importante.

{% endif %}
